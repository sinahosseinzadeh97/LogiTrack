# Sample of the Olist dataset

A 25% sample of sellers (with every order they sold) from the
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce),
regenerated with `python -m etl.sample` from `backend/`. It exists so the demo
runs without downloading anything; put the full CSVs in `data/raw/` to use
all ~99k orders instead.
